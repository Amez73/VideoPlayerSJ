# VideoPlayerSJ

Android video player app.

## Download the latest APK

Every push to `main` automatically builds a fresh debug APK via GitHub Actions.

**On your phone**, open this link in a browser and download `app-debug.apk`:

https://github.com/Amez73/VideoPlayerSJ/releases/latest

You may need to allow "install unknown apps" for your browser in Android settings the first time.
